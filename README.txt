# Orbit Eye — Homepage with Images

This package includes a more complete homepage with photographic service cards, a gallery preview, benefits, workflow, FAQ, CTA, navigation, footer, and responsive layout.

Files included:
- index.html (expanded image-rich homepage)
- about.html
- services.html
- gallery.html
- contact.html
- career.html
- Style.css

Images are loaded from Unsplash image URLs, so the browser needs an internet connection to display them.
Before publishing, verify the existing contact form, replace any placeholder/contact links with your confirmed business details, and test every page on the live Vercel deployment.
